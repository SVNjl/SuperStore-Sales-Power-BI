Objective : To contribute to the success of a business by utilizing data analysis techniques, specifically focusing on time series analysis and to provide valuable insights and accurate sales forecasting.

Methodology :-
1. Data Cleaning : Employed Power BI to eliminate nulls, errors and duplicates, ensuring data integrity. Transformed data was then loaded into report view for in-depth analysis.
2. Data Modeling : Engineered a logical data structure for effective analysis and visualization.
3. Data Implementation : Utilized DAX to create calculated column (AvgDelivery) and table (Salesforecast) for advanced analysis.
4. Data Visualization : Leveraged customized visualizations to uncover intricate data relationships, empowering user-driven insights.
5. Sales Forecasting : Leveraged historic data and applied time series analysis to generate sales forecast for the next 15 days.
